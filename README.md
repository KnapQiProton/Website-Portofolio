# 🎨 Website Portofolio - KnapQi

> Portofolio pribadi yang dibuat untuk hobi dan belajar. Jangan serius-serius amat ya 😄

## ✨ Fitur

- 🌙 **Dark & Light Mode** — Ganti tema sesuka hati
- 📊 **Stats Dynamic** — Data GitHub real-time (auto-update!)
- 🏆 **Sertifikat** — Klik buat lihat detail di modal
- 📅 **Timeline Pengalaman** — Perjalanan belajar coding
- 🎭 **Animasi Halus** — Float, tilt, glow, typewriter, dan lain-lain
- 📱 **Responsive** — Tampil bagus di semua device

## 🛠️ Tech Stack

- **HTML5** — Struktur website
- **CSS3** — Styling, animasi, CSS Variables untuk theming
- **JavaScript (Vanilla)** — Interaksi, animasi, GitHub API
- **GitHub Pages** — Hosting gratis

## 🚀 Cara Pakai

1. Clone repo ini
   ```bash
   git clone https://github.com/KnapQiProton/Website-Portofolio.git
   ```
2. Buka `index.html` di browser
3. Selesai! 🎉
